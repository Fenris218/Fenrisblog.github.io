**SMB (Server Message Block)** là **giao thức chia sẻ tệp (file sharing protocol)** được Microsoft phát triển,  dùng để **gửi yêu cầu và nhận dữ liệu từ file server hoặc thiết bị mạng**.

Cơ chế cơ bản

1. Máy **client** (ví dụ: laptop của bạn) muốn truy cập vào `\\SERVER\Share`.
2. Nó **kết nối tới máy SERVER qua TCP port 445** (hoặc 139 cho SMB cổ).
3. Nó **xác thực (authentication)** bằng tài khoản Windows (qua NTLM hoặc Kerberos).
4. Sau khi xác thực thành công, client có thể **đọc, ghi, tạo, xóa file**, v.v., giống như đang làm trên ổ đĩa cục bộ.

SMB hỗ trợ hai cách xác thực:

- **NTLM**: dùng hash của mật khẩu (đây là cái mà Responder có thể thu được nếu client bị lừa).
- **Kerberos**: an toàn hơn, thường dùng trong môi trường domain (Active Directory).
