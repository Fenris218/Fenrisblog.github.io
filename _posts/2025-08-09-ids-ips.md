## 1. Intrusion Detection System (IDS)

It is a **passive** monitor solution for detecting possible malicious activities. It generates alerts for each suspicious event. 

- NIDS : monitors the traffic flow from various areas of the network.
- HIDS : monitors activity on a single endpoint.

## 2. Intrustion Prevent System (IPS)

It is an **active** protecting solution for preventing possible activities, abnormal incidents. It is responsible for stopping/preventing/terminating the suspicious event.

There are four main types of IPS:

| Type | What it protects | What it monitors | Example use case |
| --- | --- | --- | --- |
| **Network-based IPS (NIPS)** | Entire network | Network packets | Blocking exploits, malware, port scans |
| **Host-based IPS (HIPS)** | Individual host | System calls, processes, files, registry | Preventing malware execution, blocking privilege escalation |
| **Wireless IPS (WIPS)** | Wireless networks | Wi-Fi traffic and access points | Detecting rogue APs, preventing Wi-Fi attacks |
| **Network Behavior Analysis (NBA) IPS** | Network behavior | Traffic patterns and anomalies | Detecting DDoS attacks, worms, unusual network activity |

📌 The difference between NIPS and Behaviour-based systems is that behaviour-based systems require a training period (also known as "baselining") to learn the normal traffic and differentiate the malicious traffic and threats. This model provides more efficient results against new and unknown threats.

## 3.  Detection/Prevention Techniques

There are three main detection and prevention techniques used in IDS and IPS solutions

- Signature
- Behaviour
- Policy
